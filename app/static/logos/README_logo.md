# FjordFlix logo package

The blue/cyan play symbol frames a fjord and snow-capped mountains, matching the Fjord app family. The SVG sources are editable and all exports are generated by `scripts/build_brand.py` (Pillow and Playwright are development-only dependencies).

| Use | File |
| --- | --- |
| App header, login and remote, dark background | `source/fjordflix-horizontal-dark.svg` |
| Light background | `source/fjordflix-horizontal-light.svg` |
| FjordHub catalog | `icons/fjordflix-mark-transparent-512.png` |
| iPhone/iPad home screen | `web/apple-touch-icon.png` (180 × 180, opaque) |
| Browser tabs | `web/favicon.ico`, 16/32 px PNG |
| Android / web app | `web/android-chrome-192x192.png`, `web/android-chrome-512x512.png` |
| Maskable app icon | `web/pwa-maskable-512x512.png` (extra safe padding) |
| App icon master | `logos/fjordflix-app-icon-master.png` (1024 × 1024) |
| Transparent mark and horizontal/stacked PNG logos | `logos/` |
| Editable original artwork | `source/*.svg` |

Apple and maskable icons have a full square opaque background; the operating system applies its own shape. Do not round their corners in the source. Tiny favicons use a simplified play silhouette for legibility. Dark logo variants use light lettering on a transparent background; light variants use dark lettering.

Both app pages include icon links. The manifest opens `/` and does not save a remote-pairing token. It supplies home-screen identity, not offline playback. An existing iPhone shortcut may need to be removed and added again to refresh its cached icon.

To rebuild from the repository root:

```sh
python -m pip install pillow playwright
python -m playwright install chromium
python scripts/build_brand.py
```
